# kalman_demo
1）项目介绍
这是一个模型为测量匀速运动的小车运动路程的卡尔曼滤波算法；
2)代码功能
卡尔曼滤波的计算和寻找适合的Q矩阵的算法
3）操作说明
本项目分为三个部分，第一部分matrix.h/.c文件封装了矩阵运算的算法；
第二部分kalman.h\.c文件封装了卡尔曼滤波运算和寻找适合的Q矩阵的函数；
第三部分matrix_test.c\kalman_test.c是测试文件，可以通过该文件测试代码功能；
该项目对外的接口为：寻找适合的Q矩阵时迭代的次数EPOCH、X状态矩阵的大小NUMBER_OF_X、寻找适合的Q矩阵时的步长STEP、观测矩阵Z大小NUMBER_OF_Z，观测矩阵高斯噪声方差STDDEV_G;
可以通过在kalman.h中修改相应的宏定义实现。
需要注意的是，由于作者水平限制，观测矩阵的大小为[n]即1维，本模型的模拟噪声为高斯噪声,寻找最佳Q矩阵的方式为计算迭代的均方差。
